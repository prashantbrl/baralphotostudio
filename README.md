# Baral Photo Studio — GitHub Pages

## Files
- `index.html` — complete website
- `assets/brand/logo.jpg` — supplied Baral Photo Studio logo
- `assets/photos/01.jpg` through `08.webp` — supplied portfolio photos

## Publish on GitHub Pages
1. Open the `baralphotostudio` repository.
2. Delete the old `index.html` if you are replacing it.
3. Upload **everything inside this folder** so that `index.html` is in the repository root.
4. Make sure the `assets` folder is also in the repository root.
5. Commit the changes to `main`.
6. Open **Settings → Pages**.
7. Under Build and deployment, choose **Deploy from a branch**.
8. Choose **main** and **/(root)**, then Save.

The site will publish at:
`https://YOUR-GITHUB-USERNAME.github.io/baralphotostudio/`

## Important
Keep the folder structure exactly as supplied. Do not put `index.html` inside `assets`.
