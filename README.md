- `assets/logo.png` — add the studio's real logo here and update the logo area in `index.html` if desired

## Real photos and logo
I did not include photos from other Baral studios because they could be the wrong business. To use the studio's actual images:
1. Put six JPG/PNG files in `assets/photos/`.
2. Rename them `01.jpg`, `02.jpg`, `03.jpg`, `04.jpg`, `05.jpg`, `06.jpg`.
3. Put the studio logo at `assets/logo.png`.
4. If you upload the real photos/logo to ChatGPT, I can integrate them directly and replace the temporary visual.

## Publish on GitHub Pages
1. Create a public GitHub repository, for example `baral-photo-studio`.
2. Upload `index.html`, `.nojekyll`, and the `assets` folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. GitHub will provide the live `.github.io` address.

No build command, Node.js, or server is required.
